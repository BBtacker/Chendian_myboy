# AI腺样体面容检测系统 - 设计系统

## 1. 设计理念

### 核心价值
- **专业性**：体现医疗行业的专业、权威形象
- **可信度**：通过视觉设计建立用户信任
- **清晰度**：确保信息传达清晰明了
- **亲和力**：在专业的基础上保持友好和人文关怀
- **科技感**：体现AI技术的先进性

### 设计风格
- **主风格**：现代医疗风格，简洁、专业、科技感
- **辅助风格**：温暖关怀，体现对患者的人文关怀
- **视觉语言**：清晰的层次结构，适当的留白，专业的色彩搭配

## 2. 颜色系统

### 主色调
- **主色**：#1976D2（医疗蓝）- 代表专业、信任、科技
- **辅助色**：#4CAF50（健康绿）- 代表健康、自然、希望
- **强调色**：#FF9800（温暖橙）- 代表关怀、活力

### 功能色
- **成功**：#4CAF50（健康绿）
- **警告**：#FF9800（温暖橙）
- **错误**：#F44336（警示红）
- **信息**：#2196F3（信息蓝）

### 中性色
- **背景色**：#F5F7FA（浅灰）
- **卡片背景**：#FFFFFF（白色）
- **文本色**：#333333（深灰）
- **次要文本**：#666666（中灰）
- **边框色**：#E4E7ED（浅灰）

### 渐变色
- **主渐变**：linear-gradient(135deg, #1976D2, #2196F3)
- **健康渐变**：linear-gradient(135deg, #4CAF50, #81C784)
- **关怀渐变**：linear-gradient(135deg, #FF9800, #FFB74D)

## 3. 排版系统

### 字体
- **主要字体**：'Segoe UI', Tahoma, Geneva, Verdana, sans-serif
- **标题字体**：加粗，清晰易读
- **正文字体**：常规，舒适阅读

### 字体大小
- **H1**：28px，加粗
- **H2**：24px，加粗
- **H3**：20px，加粗
- **H4**：18px，加粗
- **正文**：16px，常规
- **小文本**：14px，常规
- **微文本**：12px，常规

### 行高
- **标题**：1.2
- **正文**：1.6
- **小文本**：1.4

## 4. 组件设计

### 按钮
- **主要按钮**：主色调填充，圆角12px，阴影效果
- **次要按钮**：白色背景，边框主色调，圆角12px
- **危险按钮**：警示红填充，圆角12px
- **悬停效果**：轻微上浮，阴影加深

### 卡片
- **圆角**：16px
- **阴影**：0 8px 30px rgba(0, 0, 0, 0.12)
- **边框**：无，或1px浅灰边框
- **背景**：白色
- **悬停效果**：轻微上浮，阴影加深

### 表单
- **输入框**：圆角15px，边框浅灰，聚焦时边框主色调
- **标签**：加粗，清晰易读
- **错误提示**：警示红，小文本

### 表格
- **表头**：浅灰背景，加粗文本
- **行高**：适中，确保舒适阅读
- **边框**：1px浅灰边框
- **选中行**：浅主色调背景

### 图标
- **风格**：线性图标，简洁现代
- **颜色**：主色调或文本色
- **大小**：根据上下文调整，保持一致性

## 5. 布局系统

### 主布局
- **侧边栏**：240px宽度，深色渐变背景
- **头部**：70px高度，浅色渐变背景
- **主内容区**：自适应宽度，适当留白

### 响应式设计
- **桌面端**：完整布局，侧边栏固定
- **平板端**：侧边栏宽度减小，布局紧凑
- **移动端**：侧边栏可折叠，垂直布局

### 间距系统
- **大间距**：30px
- **中等间距**：20px
- **小间距**：15px
- **微间距**：10px

## 6. 医疗主题元素

### 视觉元素
- **医疗图标**：使用与医疗相关的图标，如心跳、医疗十字、显微镜等
- **健康元素**：使用与健康相关的视觉元素，如绿叶、水滴等
- **科技元素**：使用与AI、科技相关的视觉元素，如神经网络、数据可视化等

### 交互元素
- **进度条**：使用医疗蓝，体现专业感
- **状态指示**：使用颜色编码，清晰指示不同状态
- **反馈机制**：提供及时、清晰的操作反馈

## 7. 应用指南

### 面部分析页面
- **核心功能**：图片上传、摄像头捕获、结果展示
- **设计重点**：清晰的视觉层次，专业的结果展示，直观的用户引导

### AI助手页面
- **核心功能**：聊天界面、历史记录、语音输入
- **设计重点**：专业的医疗咨询氛围，清晰的对话界面，及时的响应反馈

### 检测记录页面
- **核心功能**：数据表格、筛选功能、导出功能
- **设计重点**：清晰的数据展示，便捷的操作界面，专业的医疗数据呈现

### 统计分析页面
- **核心功能**：数据图表、趋势分析、统计概览
- **设计重点**：专业的数据可视化，清晰的趋势展示，直观的统计结果

### 个人中心页面
- **核心功能**：用户信息管理、设置选项
- **设计重点**：简洁的表单设计，清晰的信息展示，专业的个人管理界面

## 8. 实施建议

### 代码实现
- 使用Vue 3 Composition API
- 利用Element Plus组件库
- 统一的样式变量管理
- 响应式设计原则

### 性能优化
- 图片懒加载
- 组件按需加载
- 数据缓存策略
- 优化渲染性能

### 可访问性
- 符合WCAG标准
- 键盘导航支持
- 屏幕阅读器兼容
- 高对比度模式

### 维护建议
- 模块化组件设计
- 统一的设计系统管理
- 定期更新视觉元素
- 持续用户体验优化

---

此设计系统旨在为AI腺样体面容检测系统提供专业、一致、用户友好的视觉体验，体现医疗行业的专业性和科技感，同时保持对用户的人文关怀。
