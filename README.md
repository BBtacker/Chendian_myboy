# 心影日记

心影日记是一个基于React和Spring Boot的智能日记平台，专注于为用户提供安全、温暖的情感记录空间，并通过AI技术提供心灵慰藉和支持。

## 项目结构

### 前端

- `src/App.jsx` - 应用主组件，包含路由配置
- `src/components/Sidebar.jsx` - 侧边栏导航组件
- `src/pages/` - 页面组件
  - `HomePage.jsx` - 个人主页
  - `CreateDiaryPage.jsx` - 写日记页面
  - `DiaryPage.jsx` - 日记列表页面
  - `AskPage.jsx` - AI智能聊天页面
- `src/styles/` - CSS样式文件
- `src/utils/` - 工具函数
  - `api.js` - API请求工具
  - `diaryData.js` - 日记数据管理
  - `doubaoApi.js` - 豆包API封装

### 后端

- `face_recognition/` - Spring Boot后端项目
  - `src/main/java/com/lhy/face_recognition/` - Java源代码
    - `config/` - 配置类
    - `controller/` - REST API控制器
    - `entity/` - 实体类
    - `mapper/` - MyBatis映射器
    - `service/` - 业务逻辑层
  - `src/main/resources/` - 配置文件
    - `application.yml` - 应用配置
  - `pom.xml` - Maven依赖配置

## 运行方法

### 后端

1. 确保已安装Java 17和Maven
2. 确保MySQL数据库已启动
3. 在`face_recognition/src/main/resources/application.yml`中配置数据库连接
4. 进入`face_recognition`目录，执行以下命令：

```bash
mvn spring-boot:run
```

后端服务将在`http://localhost:8080`启动

### 前端

1. 确保已安装Node.js 18和npm
2. 进入项目根目录，执行以下命令安装依赖：

```bash
npm install
```

3. 执行以下命令启动前端开发服务器：

```bash
npm run dev
```

前端应用将在`http://localhost:5173`或`http://localhost:5174`启动
